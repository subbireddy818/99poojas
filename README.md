# 99Poojas - Redesigned Web Platform (Next.js)

A modern, spiritual luxury redesign of [99Poojas.in](https://99poojas.in) built with **Next.js 14 (App Router)** and **Tailwind CSS**.

## 🌟 Key Features
- **Authentic Pooja & Homam Catalog**: Over 50+ Vedic rituals with real pricing, durations, deity info, and inclusions.
- **Dedicated Ritual & Product Pages**: In-depth ceremony pages with 5-step Vidhi, inclusions checklist, verified devotee reviews, and instant 30% advance dakshina calculation.
- **Dedicated Spiritual & Informational Routes**:
  - `/service-detail/[id]` - Dedicated pooja detail & booking wizard
  - `/category-details/[id]` - Filtered sacred category showcase
  - `/category-list` - Complete 8-category visual directory
  - `/service-list` - Full service directory with instant filter & search
  - `/about-us` - The story of 99Poojas & Vedic scholar network
  - `/help-support` - Devotee support desk, telephone helpline (+91 8885043059)
  - `/login-page` - Devotee and Pandit OTP authentication portal
  - Legal & Policies: `/term-conditions`, `/privacy-policy`, `/refund-policy`, `/data-deletion-request`
- **Interactive Multi-Step Booking**: Date picker, muhurtham time slots, Hyderabad zone selector, and coupon application.
- **Responsive & Dark Mode**: Tailored sacred color palette (deep vermilion, sacred saffron, antique gold) with seamless light/dark mode support.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+

### Installation
```bash
npm install
```

### Running Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Building for Production
```bash
npm run build
npm run start
```
